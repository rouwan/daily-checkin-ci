## 公开仓库范围

- `webapp-testing` 包含许可证，并且当前冒烟测试需要使用其中的服务管理脚本，因此随公开仓库发布。
- `fastapi`、`frontend-design`、`vue` 和 `web-design-guidelines` 缺少可直接确认的随项目分发许可证，或者不属于公开仓库运行所需内容，继续保留在本机但不提交。
- 未提交的技能仍保留来源和固定版本，需要重新安装时可按上表查找。

## 使用记录

- `frontend-design`：用于确定页面视觉语言、字体层级和唯一主视觉。
- `vue`：用于 Vue 3 `<script setup lang="ts">`、组件与响应式实现。
- `web-design-guidelines`：用于页面完成后的响应式、可访问性与交互规范检查。
- `webapp-testing`：用于启动前后端、页面验收截图，以及两条核心浏览器冒烟路径。
- FastAPI 官方技能：用于当前 FastAPI 版本的路由、Pydantic 模型、返回类型与同步业务函数写法。
