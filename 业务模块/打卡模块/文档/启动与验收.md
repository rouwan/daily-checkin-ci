# 启动与验收

> 验收日期：2026-11-22  
> 浏览器：Google Chrome 157.0.8103.51（无头模式）

## 启动顺序

推荐直接双击或运行模块根目录的 `启动.bat`：

```powershell
cd "业务模块\打卡模块"
.\启动.bat
```

该入口会：

1. 只识别并强制结束占用 `8000`、`5173` 且命令行属于本打卡项目的旧 Uvicorn/Vite 进程。
2. 同步后端依赖；前端依赖缺失时自动执行 `npm install`。
3. 分别打开后端和前端服务器窗口。
4. 等待两个服务就绪后打开 `http://127.0.0.1:5173`。

如端口被无法确认身份的程序占用，入口会停止并提示，不会强制结束无关程序。

关闭服务可双击或运行：

```powershell
.\停止.bat
```

也可以继续使用下面的手动命令。

先启动后端：

```powershell
cd "业务模块\打卡模块\功能模块\后端"
uv sync
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000
```

再启动前端：

```powershell
cd "业务模块\打卡模块\功能模块\前端"
npm install
npm run dev
```

如果新终端仍未识别 `uv`，用 `py -3.12 -m uv` 替代命令开头的 `uv`。

启动入口仅供人工使用；传入 `-NoBrowser` 可跳过自动打开浏览器，方便验收：

```powershell
.\启动.bat -NoBrowser
```

## 第一阶段：后端纯单元测试

单元测试只验证可以脱离数据库和运行服务执行的后端业务规则。

```powershell
cd "业务模块\打卡模块\功能模块\后端"
uv sync
uv run pytest -m unit -q
```

当前结果：23 个测试用例通过，执行时不连接 SQLite、不启动 FastAPI/Uvicorn、不启动前端。测试前后正式数据库文件的 SHA-256 哈希保持一致。

测试边界见[单元测试](./单元测试.md)。

## 第一阶段：单模块接口测试

接口测试在进程内调用 FastAPI，并使用独立临时 SQLite，不启动 Uvicorn、前端或浏览器。

```powershell
cd "业务模块\打卡模块\功能模块\后端"
uv sync
uv run pytest -m interface -q
```

当前结果：14 个接口测试用例通过。正式数据库文件的 SHA-256 哈希在测试前后保持一致。

接口范围见[接口测试](./接口测试.md)。

运行全部自动化测试：

```powershell
uv run pytest -q
```

当前共 37 个测试用例通过。

## 第一阶段：核心流程冒烟测试

冒烟测试启动真实 FastAPI、Vite 和 Chrome，使用独立临时 SQLite，执行两条核心用户路径。

```powershell
cd "业务模块\打卡模块"
.\测试\冒烟\运行冒烟测试.ps1
```

也可以双击 `测试/冒烟/运行冒烟测试.bat`。

当前结果：

```text
P0 冒烟路径：首次设置并打卡，刷新后数据保留，通过
P1 冒烟路径：撤销打卡，刷新后状态恢复，通过
两条冒烟路径全部通过
冒烟测试通过。
```

运行结束后服务自动停止，临时数据库自动清理，正式数据库哈希保持不变。

测试路径见[冒烟测试](./冒烟测试.md)。

## 本地配置

默认不需要环境变量。数据库会由后端首次启动时创建在：

```text
业务模块/打卡模块/功能模块/数据库/打卡.sqlite3
```

如需修改数据库位置，可参考 `配置/本地配置示例.env` 设置 `CHECKIN_DATABASE_PATH`。相对路径以 `功能模块/` 为基准。

## 已知限制

- 只支持本机单用户、单习惯，不提供账号或远程访问。
- 使用运行电脑的本地日期，不提供时区设置。
- 不提供补打卡、未来日期打卡或历史明细。
- 不提供移动端专属界面；窄屏只进行响应式重排。
- 单元测试只覆盖后端纯业务规则，不覆盖数据库、HTTP 接口、前端组件或完整用户流程。
- 接口测试覆盖单模块 HTTP 契约和临时数据库组合行为，不覆盖浏览器、真实前端请求或完整用户流程。
- 冒烟测试只覆盖首次设置打卡和撤销打卡两条核心路径。
- 第四阶段继续保留给多模块接口和模块间接口测试。
- 当前单模块测试已由第二阶段 GitHub Actions 自动执行。
- 尚未建立项目管理中台、正式代码审查流程或持续交付。
- 数据库没有迁移框架，当前通过可重复执行的建表脚本初始化。
