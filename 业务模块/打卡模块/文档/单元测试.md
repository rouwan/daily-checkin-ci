# 后端纯单元测试

> 状态：第一阶段已实施  
> 最后更新：2026-11-22

## 测试边界

第一阶段只测试可以脱离运行环境执行的后端纯业务规则：

- 不连接 SQLite。
- 不启动 FastAPI 或 Uvicorn。
- 不发送 HTTP 请求。
- 不启动前端或浏览器。
- 不依赖执行当天的真实日期。

需要数据库、HTTP 接口或浏览器才能验证的行为，不强行归入单元测试。

## 被测试规则

### 习惯名称

`normalize_habit_name` 负责：

- 去除首尾空白。
- 保留中间空白。
- 校验去除首尾空白后的长度为 1 至 40 个字符。

请求模型和后端服务共用这条规则，避免两处分别维护。

### 当前连续天数

`calculate_current_streak` 只接收日期集合和“今天”，负责：

- 今天已打卡时从今天向前计算。
- 今天未打卡、昨天已打卡时从昨天向前计算。
- 今天和昨天都未打卡时返回零。
- 遇到日期缺口时停止。
- 忽略未来日期。
- 正确处理跨月、闰日和跨年。

## 运行方式

```powershell
cd "业务模块\打卡模块\功能模块\后端"
uv sync
uv run pytest -m unit -q
```

测试使用项目开发依赖组中的 pytest，不需要预先启动前后端服务。
`pyproject.toml` 同时配置单元测试和接口测试目录，`-m unit` 只选择本文件描述的纯单元测试。
