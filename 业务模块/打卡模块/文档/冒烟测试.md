# 核心流程冒烟测试

> 状态：第一阶段已实施  
> 最后更新：2026-11-22

## 测试边界

- 启动真实 FastAPI 和 Vite 前端。
- 本机默认使用真实 Chrome 和 Playwright `1.60.0` 操作页面。
- CI 通过 `CHECKIN_SMOKE_BROWSER_CHANNEL=bundled` 使用 Playwright 安装的 Chromium。
- 每个测试运行使用系统临时目录中的独立 SQLite。
- 不读写正式 `功能模块/数据库/打卡.sqlite3`。
- 执行结束后关闭本次启动的服务并清理临时数据库。

冒烟测试只保留两条最有价值的主路径，不承担接口边界和视觉验收。

## P0：首次设置并完成今天打卡

```text
空数据库
→ 打开网页
→ 输入习惯名称
→ 保存
→ 点击“完成今天”
→ 显示今日已打卡、连续 1 天
→ 刷新页面
→ 仍显示已打卡、连续 1 天
```

验证前端、HTTP 接口、后端业务和 SQLite 的完整核心链路，并确认页面刷新后能够重新读取持久化数据。

## P1：撤销今天的打卡

```text
今天已打卡
→ 点击“撤销今天的打卡”
→ 确认撤销
→ 显示未打卡、连续 0 天
→ 刷新页面
→ 仍未打卡、连续 0 天
```

验证撤销交互、删除接口、状态重算和刷新后的持久化结果。

## 运行方式

在文件资源管理器中双击：

```text
测试/冒烟/运行冒烟测试.bat
```

或在模块根目录执行：

```powershell
.\测试\冒烟\运行冒烟测试.ps1
```

运行前需要保证 `8000` 和 `5173` 端口空闲。启动器会：

1. 创建独立临时数据库。
2. 启动 `webapp-testing` 技能中的服务器管理脚本。
3. 启动真实 FastAPI 和 Vite。
4. 使用 Chrome 执行 P0、P1 两条路径。
5. 停止本次启动的前后端服务。
6. 清理本次临时数据库。

如果端口已被其他程序占用，启动器会停止并提示，不会结束无关进程。

## Windows 启动文件编码

- `运行冒烟测试.bat` 使用 Windows `CRLF` 换行。
- `运行冒烟测试.ps1` 使用带 BOM 的 UTF-8 编码。

批处理文件如果只有 Unix `LF` 换行，`cmd.exe` 会把命令拆错并返回退出码 `9009`。Windows PowerShell 5.1 读取无 BOM 的中文 PowerShell 脚本时也可能出现乱码和语法错误。

## 当前结果

```text
P0 冒烟路径：首次设置并打卡，刷新后数据保留，通过
P1 冒烟路径：撤销打卡，刷新后状态恢复，通过
两条冒烟路径全部通过
冒烟测试通过。
```

正式数据库哈希在冒烟测试前后保持一致，运行结束后两个服务端口均已释放。

## 暂不放入冒烟

- 空名称、超长名称等校验边界。
- 重复打卡的数据库幂等细节。
- 修改名称后保留打卡。
- 连续天数跨月、跨年或闰日。
- 响应式布局和键盘可访问性。
- 后端进程重启后的持久化。

上述边界继续由单元测试、接口测试和前端页面验收覆盖。
