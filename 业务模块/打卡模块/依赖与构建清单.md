## 构建方式

- 前端使用 npm 安装依赖，Vite 构建。
- 前端依赖锁定文件：`功能模块/前端/package-lock.json`。
- 后端使用 uv 管理虚拟环境和依赖。
- 后端依赖锁定文件：`功能模块/后端/uv.lock`。
- SQLite 使用单文件数据库，不启动独立数据库服务。
- 前端构建产物：`功能模块/前端/dist/`。

## 常用命令

```powershell
# 一键启动（会先清理本项目旧进程）
cd "业务模块\打卡模块"
.\启动.bat

# 一键停止
.\停止.bat

# 前端
cd "业务模块\打卡模块\功能模块\前端"
npm install
npm run dev
npm run build

# 后端
cd "业务模块\打卡模块\功能模块\后端"
uv sync
uv run pytest -m unit -q
uv run pytest -m interface -q
uv run pytest -q
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000

# 冒烟测试
cd "业务模块\打卡模块"
.\测试\冒烟\运行冒烟测试.ps1
```

若当前终端尚未刷新用户 PATH，可将后端命令中的 `uv` 写成 `py -3.12 -m uv`。

- `uv run pytest -m unit -q` 只执行后端纯单元测试。
- `uv run pytest -m interface -q` 只执行单模块 HTTP 接口测试。
- `uv run pytest -q` 执行全部自动化测试。
- 接口测试使用独立临时 SQLite，不启动 Uvicorn、前端或浏览器。
- 冒烟测试自动启动真实前后端和 Chrome，使用独立临时 SQLite，并在结束后关闭服务。
