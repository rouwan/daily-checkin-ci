# 打卡模块目录说明

本目录是项目第一版唯一的业务模块，包含前端、后端、数据库、接口、测试、配置和技能。

## 目录结构

```text
打卡模块/
├── 功能模块/
│   ├── 前端/
│   ├── 后端/
│   │   └── app/
│   └── 数据库/
├── 启动.bat
├── 停止.bat
├── server-control.ps1
├── 接口/
├── 测试/
│   ├── 单元/
│   │   └── 后端/
│   ├── 接口/
│   │   └── 后端/
│   ├── 冒烟/
│   │   ├── 核心流程.py
│   │   ├── 运行冒烟测试.ps1
│   │   └── 运行冒烟测试.bat
│   └── 前端页面验收/
│       ├── 页面验收.py
│       └── 验收截图/
├── 配置/
├── 技能/
├── 文档/
├── 目录说明.md
└── 依赖与构建清单.md
```

## 各目录职责

| 目录或文件 | 职责 |
| --- | --- |
| `功能模块/前端/` | 网页界面和页面布局 |
| `功能模块/后端/` | 后端应用、业务规则和数据库访问 |
| `功能模块/后端/app/rules.py` | 可脱离数据库执行的纯业务规则 |
| `功能模块/数据库/` | 建表脚本、初始化和后续迁移文件 |
| `启动.bat` | 人工一键启动入口，先清理本项目旧服务再启动前后端 |
| `停止.bat` | 停止本项目占用 `8000` 和 `5173` 的服务 |
| `server-control.ps1` | 启动入口使用的进程识别、清理、启动与就绪检查逻辑 |
| `接口/` | 前后端之间的接口约定与调用示例 |
| `测试/` | 模块统一测试入口，按单元、接口、冒烟和人工验收分层 |
| `测试/单元/后端/` | 后端纯单元测试，不连接数据库或接口 |
| `测试/接口/后端/` | 单模块 HTTP 接口测试，使用进程内客户端和临时数据库 |
| `测试/冒烟/` | 两条核心用户路径的真实浏览器冒烟测试和隔离启动器 |
| `测试/前端页面验收/` | 人工浏览器页面验收脚本和使用说明、截图 |
| `配置/` | 本地运行参数和配置示例 |
| `技能/` | 本项目使用的设计、实现和验收技能 |
| `文档/` | 打卡模块自己的记忆和技术选型 |
| `依赖与构建清单.md` | 记录技术依赖、安装状态和构建方式 |

## 当前状态

第一阶段已完成：前端、后端和 SQLite 数据库脚手架已建立，业务闭环可本地运行，并提供带旧进程清理的一键启动入口。

第一阶段已完成：后端纯业务规则有 23 个单元测试；单模块 HTTP 接口有 14 个接口测试；核心用户流程有 2 条真实浏览器冒烟测试。冒烟测试使用独立临时数据库，并自动启动、停止前后端。人工前端页面验收脚本和截图收纳在 `测试/前端页面验收/`。第二阶段范围等待用户确认；第四阶段继续保留给多模块接口测试，第五阶段继续保留给持续集成。
