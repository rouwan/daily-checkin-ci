# 打卡接口约定

> 版本：1.0  
> 最后更新：2026-11-22

## 基本信息

- 后端地址：`http://127.0.0.1:8000`
- 接口前缀：`/api`
- 请求与响应格式：`application/json`
- 日期：使用后端所在电脑的本地日期，格式为 `YYYY-MM-DD`
- 数据库：仅由后端访问

## 今日状态

`GET /api/status`

返回唯一习惯、今天是否打卡以及当前连续天数。

```json
{
  "habit": {
    "name": "读书半小时"
  },
  "date": "2026-11-22",
  "checked_in_today": true,
  "current_streak": 3
}
```

尚未设置习惯时，`habit` 为 `null`。

## 设置或修改习惯

`PUT /api/habit`

```json
{
  "name": "读书半小时"
}
```

规则：

- 名称去除首尾空白后必须为 1 至 40 个字符。
- 系统中始终只有一个习惯名称。
- 修改名称不会删除已有打卡记录。
- 成功返回最新的今日状态。
- 名称为空或超长时返回 `422`。

## 完成今天打卡

`POST /api/check-ins/today`

- 只创建今天这一天的记录。
- 重复调用不会新增第二条记录。
- 尚未设置习惯时返回 `409`。
- 成功返回最新的今日状态。

## 撤销今天打卡

`DELETE /api/check-ins/today`

- 只删除今天这一天的记录。
- 今天没有记录时也返回成功，便于安全重试。
- 成功返回重新计算后的今日状态。

## 运行检查

`GET /api/health`

```json
{
  "status": "ok"
}
```

## 连续天数响应规则

1. 今天已打卡：从今天向前逐日计算。
2. 今天未打卡且昨天已打卡：从昨天向前逐日计算。
3. 昨天未打卡：当前连续天数为 `0`。

## 自动化验证

单模块 HTTP 接口测试位于 `测试/接口/后端/`，使用进程内 FastAPI 测试客户端和独立临时 SQLite。

```powershell
cd "业务模块\打卡模块\功能模块\后端"
uv run pytest -m interface -q
```

接口测试不启动 Uvicorn、前端或浏览器。测试范围见[接口测试](../文档/接口测试.md)。
